# Документация по игре «Battleship»

## Запуск игры

После запуска программы пользователю предлагается выбрать режим игры:
- 0 - игра против бота;
- 1 - игра против другого игрока;
- 2 - автоматическая игра двух ботов;
- 3 - выход из программы.

## Регистрация игроков
Перед началом партии игрок вводит своё имя. После регистрации выполняется расстановка кораблей.

## Расстановка кораблей
Доступны два режима расстановки:
- 0 - ручная расстановка;
- 1 - автоматическая расстановка.

При ручной расстановке необходимо указать размер корабля, ориентацию (горизонтально или вертикально) и координаты размещения.

## Ход игры

Во время игры отображается собственное поле игрока и поле противника с результатами произведённых выстрелов.

Для выстрела необходимо ввести координаты клетки.
Результаты выстрелов:
- **мимо** - попадание не произошло;
- **попал** - повреждена палуба корабля;
- **убил** - корабль полностью уничтожен.
При попадании игрок получает дополнительный ход. После промаха ход передаётся противнику.

## Завершение игры
Игра завершается после уничтожения всех кораблей одного из игроков.
Все завершённые партии автоматически сохраняются в каталог `gameList`.
Каждый файл содержит историю ходов, итоговое состояние полей игроков и игровую статистику.

## Режим администратора
Для входа в режим администратора необходимо ввести имя: `admin`

Доступные команды:
- 1 - показать список сохранённых игр;
- 2 - показать список архивных игр;
- 3 - просмотреть сохранённую игру;
- 4 - переместить игру в архив;
- 5 - восстановить игру из архива;
- 6 - удалить игру;
- 0 - выйти из режима администратора.
